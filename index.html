Numbers Center · Центр цифр

A personal analytics tool for one creator's own YouTube channels.

It reads viewing statistics of the owner's channels through the YouTube Data API and YouTube Analytics API with read-only access and shows them on the owner's own computer. It does not upload, edit or publish anything, and it is not offered to anyone else.

Личное приложение одного автора: показывает статистику его собственных каналов YouTube. Доступ только на чтение. Ничего не загружает и не меняет, другим людям не предлагается.
